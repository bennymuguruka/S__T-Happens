# Possible UI arrangements

Saved on 2026-10-09 as visual references for future UI work. These are options, not a selected final design.

- [UI components](01-ui-components.png): logos, buttons, cards, player icons, timer, results and pity voting.
- [Style and scoring](02-ui-style-and-scoring.png): button states, score displays, card counts and game feedback.
- [Layout options](03-ui-layout-options.png): lobby elements, scenario cards, controls and progress indicators.
- [Host and phone screens](04-host-and-phone-screens.png): menu, lobby, round, phone, results, pity and game-over arrangements.

Use the yellow, black and white palette, bold typography, rounded panels and colourful player identities as possible design directions.

Current gameplay rules take precedence over text and controls in these images:

- Players begin with two revealed cards in an ordered personal scale.
- Players choose a gap in their scale; the mockup's continuous numeric slider is not the current placement mechanic.
- The active scenario's Misery Index remains hidden until reveal, including on phones.
- Each player can submit once per round; a change-answer control must not allow resubmission.
- Fastest correct earns 15 points and the card; other correct players earn 7 points and the card; wrong answers earn 0.
- Winning the pity vote earns 3 score points, without pity-to-card conversion.
- When someone reaches 100 points, finish the round including pity voting, then the highest score wins.
- Fixed round totals, player caps and tie-breaking shown or implied in the mockups are not established rules.
